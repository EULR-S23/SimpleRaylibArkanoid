# Arkanoid

Just a classical Arkanoid made for fun and to get out of student debt.

## 🛠 Tech Stack
*   **Language:** C++
*   **Library:** Raylib
*   **IDE:** Visual Studio 2022

## 🚀 Features
*   Paddle control (A/D or Arrow Keys).
*   Destructible blocks with different durability.
*   Power-ups (falling drops):
    *   **W (Wide):** Expands the paddle.
    *   **S (Slow):** Slows down the ball.
    *   **M (Multi):** Spawns an additional ball.
*   Score, lives, and victory/game over screens.
